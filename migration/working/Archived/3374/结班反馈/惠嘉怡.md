
#### **【完成情况】**

准确率：共40题，正确9个，（第一篇3道，第二篇4道，第三篇2道）

预估雅思对应分数：4-4.5分左右

#### **【本阶段学习分析】**

**学生优势：**

1. 对基础题型（如笔记填空、图表填空）的解题流程有初步认知，结班测中该类题型存在部分正确作答情况，体现课程中基础技能讲解的吸收效果。  
2. 在熟悉话题的题目中（如与“play”相关的笔记填空部分题目），能捕捉到部分核心词汇，展现一定的词汇基础联想能力。  
3. 学员自身的英语基础其实很好，词汇量有优势且具备一定语感，单句翻译基本没有问题。


**提升项：**

1. 题型适应能力不足：结班测采用剑雅真题（难度高于课程教材），面对段落配信息、人名配信息、段落配标题等复杂题型时，解题逻辑模糊，定位与匹配效率低，错误率居高不下。  
2. 词汇与同义替换短板：题干与原文的词汇对应、词义理解偏差明显，摘要填空、判断类题型中因词汇理解失误导致判断错误。  
3. 题型规则掌握不牢：TF/YN/NG、段落匹配等题型的评分规则（如NOT GIVEN的判定边界）把握不准，出现“TRUE误判为NG”“NO误判为NOT GIVEN”等情况。  
4. 时间分配不合理：3篇文章40题的限时压力下，答题节奏紊乱，部分题目未充分分析就仓促作答。  学员自身也没有调整到最佳状态，并以认真的态度对待测试。


#### **【复习建议】**

1. 题型专项攻坚：针对段落配信息、人名配信息等薄弱题型，结合剑雅真题拆解“划关键词→定位原文→逻辑匹配”步骤，每日精练2 - 3组对应题型，强化解题逻辑。  
2. 同义替换积累：整理剑雅真题及课程教材中高频同义替换词（按“动词/名词/形容词 + 替换表达”分类），早晚各花15分钟诵读记忆，重点关注笔记填空、摘要填空类题型的主题词汇。  
3. 错题深度复盘：将结班测错题按“题型 + 错误原因（词汇/定位/规则）”分类，每类总结2 - 3条避坑技巧（如TF题中“绝对化表述≠错误，需看原文是否存在”），每周复盘1次错题集。  
4. 限时模拟训练：以剑雅真题为素材，严格按照“每篇20分钟”限时训练，训练前先浏览全卷题型分布，优先完成优势题型，培养时间敏感度与答题节奏。
