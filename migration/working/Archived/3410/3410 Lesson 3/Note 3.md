# 判断题
**原则**：一切以原文为主，切忌过度推断 

**F 和 NG 如何区分**
F：相反/冲突的证据
NG：关键词定位不全 

**小技巧：兼容性判断**
原文信息和题干信息能否同时出现
能：信息兼容，NG
不能：不兼容，F

### 考点划分
**小技巧**：假设法
*如果判 F，文中会出现什么样的信息？*

**方法论**：
- more than / rather than   **than x 2**
- most / only / first 绝对词  **政治题考点**
- 方向性表达
- 客观信息
	- 介词短语
	- 逻辑关系
