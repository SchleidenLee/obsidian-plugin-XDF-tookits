# 判断题
### F和NG的区分
**定义**：
**F**：有相反/冲突信息
**NG**：关键词定位不全 

**小技巧**：兼容性判断
*题干信息和原文信息能否同时出现？*
**能**：兼容，NG
**不能**：不兼容，F

### 判断题考点划分
**小技巧**：假设法
*如果这道题判 F，哪个信息会出错？*

**方法论**
- more than / rather than   **than x 2**
- most / only / first **绝对词/政治题考点**
- 方向性表达 
1. 客观信息
	1. 介词短语
	2. 逻辑关系
