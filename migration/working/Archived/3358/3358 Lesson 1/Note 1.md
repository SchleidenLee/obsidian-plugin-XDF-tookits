# TFNG 判断题
**T**：信息和原文一致
**F**：信息和原文相反/冲突
**NG**：未提及

## F和 NG 的区分 
- F 需要有证据，NG 不需要证据 
**兼容性判断**
*题干和原文信息能否同时出现*
- 能：NG
- 不能：F

## 考点划分
### 假设法
*如果这道题判 F，哪个信息最容易出错？*
### 方法论
- more than / rather than 
- most / only / first   政治题考点
- 方向性表达

# 填空题
> [!note] 
>  原词填空
>  有词数限制

## 解题步骤
1. 划关键词
	- 做预测（词性，词义，词形，时态）
	- 空前空后划关键词
2. 定位
	- 合理利用额外信息 
3. 解题
	- 检查：词数，词性，翻译

# 长难句分析
1. 找谓语动词 
	- **非谓语**：to do / doing / done
2. 划分从句和修饰结构
	- n 个动词，n-1 个从句/并列句
	- 介词短语，不定式
3. 翻译 
	- 适当调整表达
