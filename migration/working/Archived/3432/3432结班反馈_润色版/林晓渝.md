#### **【完成情况】**

学员参加了结班测

#### **【本阶段学习分析】**

**学生优势：**

1. **学习态度端正、习惯良好**：全程全勤、无迟到早退，作业均能按时认真提交，自律性较强，为后续提分打下了很好的意志力基础。
2. **词汇基础扎实，简单定位能力较强**：结班测填空题中能准确拼写并填入多个基础词汇；结合 L1 反馈，关键词划分较合理，具备较好的基础词汇储备和初步扫读定位能力。
3. **部分基础题型掌握较好**：L3 课堂判断题出门测表现良好，结班测第一篇判断题前几题也全部答对，说明对基础判断逻辑和简单同义替换已有一定理解，具备继续攻克复杂题型的潜力。

**提升项：**

1. **判断题 FALSE 与 NOT GIVEN 边界可再清晰**：细节精确理解仍有提升空间，偶有“原文矛盾”与“未提及”区分不清的情况，同义替换识别也需继续加强。
2. **信息匹配题与段落精读能力可再提高**：面对较长段落时，主旨概括和细节匹配还不够稳，长难句处理与抗原词干扰能力有待加强。
3. **填空题词性预测与语法检查需固化**：定位后仍有词性不符、字数超限等情况，说明“预测—检查”步骤还需养成习惯。
4. **课堂互动可更主动**：目前偏被动应答，若能更主动提问与分享思路，思维活跃度与吸收效率会更高。

#### **【复习建议】**

1. **建立判断题 F / NG 错题本并强化同义替换**：每周精析若干易混淆错题，强制写出原文定位句，并用一句话总结“原文如何与题目矛盾”或“原文缺失什么条件”。
2. **实施“段落主旨 + 同义替换”双线精读**：每周完成 2 篇信息匹配题，做题后对每段做一句话主旨概括，并整理题目与原文的同义替换词对。
3. **固化填空题“预判—定位—检查”三步法**：定位前标注所需词性与预估字数，填入后再做语法与逻辑二次检查，减少词性误用和字数问题。
4. **设定课堂主动互动小目标**：每节课至少主动提出 1 个问题，或分享 1 道错题思路，通过增加互动频次提升思维活跃度。
