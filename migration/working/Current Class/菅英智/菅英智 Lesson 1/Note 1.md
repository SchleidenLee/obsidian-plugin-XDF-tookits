# 判断题 
## F 和 NG 的区分
**定义：**
	F：有相反/冲突信息 
	NG：关键词定位不全 
**小技巧：兼容性判断**
*题干信息和原文信息能否同时出现？*
	能：兼容，NG
	不能：不兼容：F

## 考点划分 
原则：主语不出题，主干不出题
**小技巧**：假设法
*假如判 F，文中会出现什么样的信息？*
**方法论**
- more than / rather than 
- most / only / first / last 绝对词 政治题考点 
- 方向性表达：能放在数轴上的信息
2. 客观信息点
