# 判断题TFNG
## F和NG的区分
**F**：需要有证据 
**NG**：关键词定位不全 
技巧：**兼容性判断**
*文中信息和题干信息能否同时出现？*
**能，兼容**：NG
**不能，不兼容：** F
## 考点划分
**小技巧**：假设法
	*如果判F，哪个信息会出错？*
**方法论**：
- rather than / more than  
- most / only / first  绝对词 政治题考点 
- 方向性表达
