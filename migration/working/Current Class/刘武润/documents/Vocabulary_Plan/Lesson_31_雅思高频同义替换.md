# Lesson 31: 雅思高频同义替换 (2)

> **目标**: 深化同义替换能力，掌握名词和形容词的高级表达，扩展文化类词汇。

## 🔴 必改错词 (滚动复习 - 动词同义替换)
*检查上节课动词替换的掌握情况*
1.  **say vs state vs claim** - 说 (*语气递增*)
2.  **think vs believe vs argue** - 认为
3.  **get vs obtain vs acquire** - 获得
4.  **give vs provide vs offer** - 给予
5.  **use vs utilize vs employ** - 使用
6.  **help vs assist vs facilitate** - 帮助
7.  **show vs demonstrate vs illustrate** - 展示

## 🟢 基础回填词 (常见名词·升级准备)
*这些是学员目前过度使用的"小白词"，需要升级*
8.  **thing** → **item / object / element / aspect**
9.  **part** → **section / segment / component / portion**
10. **way** → **method / approach / means / manner**
11. **problem** → **issue / difficulty / challenge / obstacle**
12. **answer** → **solution / response / reply / resolution**
13. **idea** → **concept / notion / thought / perspective**
14. **fact** → **reality / truth / evidence / data**
15. **result** → **outcome / consequence / effect / impact**
16. **reason** → **cause / factor / justification / rationale**
17. **example** → **instance / case / illustration / specimen**
18. **change** → ** alteration / modification / transformation / shift**
19. **difference** → **distinction / variation / discrepancy / contrast**

## 🔵 雅思进阶词 (同义替换·形容词篇)
*提升写作形容词多样性的必备词*
20. **important** → **crucial / vital / essential / significant / paramount**
21. **good** → **beneficial / favorable / positive / advantageous**
22. **bad** → **detrimental / harmful / adverse / negative**
23. **big** → **substantial / considerable / significant / massive**
24. **small** → **minimal / negligible / slight / marginal**
25. **many** → **numerous / countless / a multitude of / a plethora of**
26. **few** → **scarce / limited / insufficient / minimal**
27. **clear** → **obvious / evident / apparent / explicit**
28. **possible** → **feasible / viable / achievable / attainable**
29. **necessary** → **essential / indispensable / imperative / required**
30. **common** → **widespread / prevalent / ubiquitous / universal**

## ⚡ 核心语法攻坚：形容词副词的高级用法
> **痛点**: 形容词堆砌，不会用副词修饰，程度表达单一
> **策略**: 
> 1. 使用程度副词增强语气 (extremely, remarkably, significantly)
> 2. 使用形容词短语作后置定语
> 3. 使用分词作形容词 (interesting vs interested)

**典型例句**:
- 原句: The problem is **big**.
- 修改: The problem is **extremely significant**.

- 原句: This is a **good** method.
- 修改: This is a **highly effective** approach.

- 原句: He is **interested** in the book. The book is **interesting**.
- 修改: He is **deeply fascinated** by the **thought-provoking** book.

- 原句: The city is **big** and **busy**.
- 修改: The city is **remarkably vast** and **exceptionally bustling**.

**课堂指令建议**:
给出简单句，要求学员用程度副词和高级形容词扩展；给出中文句子，要求翻译时避免使用"very + 原级"的结构。
