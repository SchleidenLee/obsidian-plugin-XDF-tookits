
### 一、核心语法

#### 1️⃣ 形容词与副词的转换与用法
- **结构**：形容词 + -ly → 副词 (e.g., effective → effectively)
- **用法**：形容词修饰名词，副词修饰动词、形容词或其他副词。
- **例句**：
    - This is an **effective** method. (形容词修饰名词 method)
    - She solved the problem **effectively**. (副词修饰动词 solved)


#### 2️⃣ 形容词与名词的转换与用法
- **结构**：动词/形容词 + -tion/-sion → 名词 (e.g., explain → explanation; form → formation)
- **用法**：名词在句中作主语、宾语或表语。
- **例句**：
    - Can you give me an **explanation**? (名词作宾语)
    - The **formation** of the group took a long time. (名词作主语)


### 二、固定搭配/用法

- **in the same way**
    - **意思**：以同样的方式
    - **例句**：You should treat everyone **in the same way**.

- **work out**
    - **意思**：解决；想出；锻炼
    - **例句**：We need to **work out** a solution to this problem.

- **pay attention to**
    - **意思**：注意，关注
    - **例句**：Please **pay attention to** the teacher.

- **a reason for**
    - **意思**：……的理由
    - **例句**：There is no **reason for** being late.
