## 1️⃣ General Words

| Word / Phrase | Meaning | Example |
|---------------|----------|----------|
| related to | 与……有关 | This topic is related to health. |
| likely | 可能的 | It is likely to rain. |
| form | 形成 | Good habits form over time. |
| security | 安全 | Security is important. |
| suffer from | 遭受 | He suffers from stress. |
| contain | 包含；容纳 | The box contains books. |
| natural | 自然的 | This area is very natural. |
| surround | 围绕 | Trees surround the house. |
| privacy | 隐私 | Everyone needs privacy. |
| permanently | 永久地 | He moved there permanently. |
| pleasant | 舒服的 | It is a pleasant day. |
| equip | 装备 | The room is equipped with a lamp. |
| fixed | 固定的 | The table is fixed to the floor. |
| transparent | 透明的 | The glass is transparent. |
| suit | 适合 | This job suits him. |
| couple | 夫妻；一对 | A couple lives here. |
| lack | 缺少 | Many areas lack water. |
| shortage | 短缺 | There is a water shortage. |
| attention | 注意 | Pay attention to the teacher. |
| protect | 保护 | We must protect the environment. |
| make use of | 利用 | We should make use of time. |
| ideal | 理想的 | This is an ideal place to live. |

## 4️⃣ 固定搭配

be made of（看得出原材料）  
be made from（看不出原材料）  

of：翻译成“的”，通常从后往前翻译  
a cup of tea → 一杯茶  

---

## 5️⃣ 介词

for：为了；对……来说
