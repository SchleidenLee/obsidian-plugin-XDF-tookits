# 阅读法

**目的**：定位关键词
- 逐行快速默读
- 不跳行
### 略读

# 判断题
### F和NG
**小技巧**：兼容性判断
*原文信息和题干信息能否同时出现？*
	能：兼容，NG
	不能：不兼容，F
**定义**：
- F：相反/冲突信息
- NG：关键词定位不全

### 考点划分
原则：主语不出题，主干不出题，

**小技巧**：假设法
*如果判F，哪个信息会出错？*
**方法论**：
- more than / rather than 
- most / only / first 绝对词 
- 方向性表达 
2. 客观信息点
	- 介词短语
	- 逻辑关系
