# Lesson 30: 雅思高频同义替换 (1)

> **目标**: 突破词汇多样性瓶颈，掌握写作口语必备同义词，避免重复用词。

## 🔴 必改错词 (滚动复习 - 条件句相关)
*检查 if 从句的时态运用*
1.  **if** - 如果 (*主将从现*)
2.  **will** - 将 (*if 从句中不能用*)
3.  **would** - 将 (*虚拟语气主句*)
4.  **were** - 是 (*虚拟语气中所有人称用 were*)
5.  **unless** - 除非 (= if not)
6.  **as long as** - 只要
7.  **provided that** - 假如 (*正式*)

## 🟢 基础回填词 (常见形容词·升级准备)
*这些是学员目前过度使用的"小白词"，需要升级*
8.  **good** → **excellent / outstanding / remarkable**
9.  **bad** → **terrible / awful / dreadful**
10. **big** → **large / huge / enormous**
11. **small** → **tiny / little / minor**
12. **happy** → **glad / delighted / pleased**
13. **sad** → **unhappy / sorrowful / depressed**
14. **angry** → **furious / annoyed / irritated**
15. **tired** → **exhausted / weary / fatigued**
16. **busy** → **occupied / engaged / swamped**
17. **easy** → **simple / effortless / straightforward**
18. **difficult** → **hard / challenging / demanding**
19. **important** → **crucial / vital / significant**

## 🔵 雅思进阶词 (同义替换·动词篇)
*提升写作动词多样性的必备词*
20. **say** → **state / claim / argue / assert**
21. **think** → **believe / consider / maintain / hold the view**
22. **know** → **be aware of / recognize / realize**
23. **get** → **obtain / acquire / gain / receive**
24. **give** → **provide / offer / supply / present**
25. **make** → **create / produce / manufacture / generate**
26. **use** → **utilize / employ / apply / make use of**
27. **help** → **assist / aid / support / facilitate**
28. **show** → **demonstrate / illustrate / reveal / indicate**
29. **change** → **alter / modify / transform / convert**
30. **improve** → **enhance / boost / upgrade / refine**

## ⚡ 核心语法攻坚：同义替换与词汇多样性
> **痛点**: 写作中反复使用同一个词，词汇单一
> **策略**: 
> 1. 使用同义词替换
> 2. 使用代词指代
> 3. 使用上下义词
> 4. 使用词性转换

**典型例句**:
- 原句: Technology is **good**. Technology makes life **good**.
- 修改: Technology is **beneficial**. It makes life **better**.

- 原句: Many **people** think... Many **people** believe...
- 修改: Many **individuals** argue... **Others** maintain...

- 原句: The **government** should **do** something. The **government** should **make** policies.
- 修改: The **authorities** should **take** measures. **They** should **implement** policies.

**课堂指令建议**:
给出一段重复用词的短文，要求学员用同义词替换划线的词；给出一个简单词 (如 important)，要求学员在 1 分钟内说出 5 个同义词。
