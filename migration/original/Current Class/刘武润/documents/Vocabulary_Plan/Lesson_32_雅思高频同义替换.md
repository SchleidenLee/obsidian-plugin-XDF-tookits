## 🟢 基础回填词 (逻辑连接·高级替换)
*替代基础的 and/but/so/because*
8.  **and** → **furthermore / moreover / in addition / additionally**
9.  **but** → **however / nevertheless / nonetheless / whereas**
10. **so** → **therefore / consequently / thus / hence / as a result**
11. **because** → **due to / owing to / on account of / in view of**
12. **first** → **initially / to begin with / in the first place**
13. **then** → **subsequently / afterwards / consequently**
14. **finally** → **ultimately / eventually / in conclusion**
15. **also** → **likewise / similarly / correspondingly**
16. **instead** → **alternatively / on the contrary / conversely**
17. **especially** → **particularly / notably / specifically**
18. **generally** → **overall / broadly speaking / in general**
19. **actually** → **in fact / as a matter of fact / indeed**

## ⚡ 核心语法攻坚：段落结构与逻辑连贯
> **痛点**: 句子之间缺乏逻辑连接，文章像"单词列表"
> **策略**: 
> 1. 使用逻辑连接词明确句间关系
> 2. 使用代词指代避免重复
> 3. 使用主题句 + 支持句 + 结论句结构

**典型段落结构**:
- **主题句**: Technology has **significantly** improved our lives.
- **支持句 1**: **Firstly**, it makes communication **much easier**. For example, we can video call anyone anywhere.
- **支持句 2**: **Furthermore**, technology has **revolutionized** education. **Specifically**, online courses allow flexible learning.
- **支持句 3**: **However**, there are **some drawbacks**. **Excessive** use of devices can lead to health problems.
- **结论句**: **Overall**, while technology brings challenges, its benefits are **undeniably substantial**.

**课堂指令建议**:
给出一个话题 (如：Should students use phones in school?)，要求学员用本节课的逻辑词写一个 5 句段落；给出一段无连接词的短文，要求学员添加合适的逻辑词。
