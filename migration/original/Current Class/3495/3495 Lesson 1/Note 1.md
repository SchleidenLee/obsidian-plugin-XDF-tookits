# 判断题
### F和NG的区分
**定义**
F：冲突信息/相反信息
NG：关键词不全 
**小技巧**：兼容性判断
*原文信息和题干信息能否同时出现*
- 能：信息兼容，NG
- 不能：不兼容，F

### 考点划分
**小技巧**：假设法 
*如果这道题判 F，哪个信息会出错？*
**方法论**
- more than / rather than  
- most / only / first 绝对词 政治题考点 
- 方向性表达 
2. 客观信息
	- 介词短语
	- 逻辑关系
