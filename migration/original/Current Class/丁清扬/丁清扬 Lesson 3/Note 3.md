# TFNG
### F和NG的区分
#### 定义
**F**：和原文冲突/相反
**NG**：关键词定位不全/不相关
#### 小技巧
**兼容性判断**
*原文信息能否和题干信息同时出现？*
**能**：兼容，NG
**不能**：不兼容，F
### 考点划分
#### 小技巧
**假设法**：如果判 F，原文会出现什么样的信息？
### 方法论
- more than / rather than  **than x 2**
- most / only / first **绝对词，政治题考点**
- 方向性表达
