# 判断题
**一切以原文为主，切忌过度推断**
**下判断时，关注方向，不抠字眼**
### F和NG的区分
**F**：有冲突/相反的证据
**NG**：关键词定位不全

**小技巧**：兼容性判断
*原文信息和题干信息能否同时出现？*
**能**：兼容，NG
**不能**：不兼容，F

### 考点划分
**小技巧**：假设法
*如果这道题要判 F，哪个信息会出错？*

**方法论**
- more than / rather than
- most / only / first ..... 绝对词 **政治题考点** 
- 方向性表达（能放在数轴上的）
- 客观信息
	- 介词短语
	- 逻辑关系 
**一般情况主语不出题**
