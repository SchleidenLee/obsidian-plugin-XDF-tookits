# 判断题
### F和NG如何区分
**定义** 
	**F**：相反/冲突证据
	**NG**：关键词定位不全 
**兼容性判断**
	*原文信息和题干能否同时出现？*
	**兼容**：NG
	**不兼容**：F

### 考点划分
> [!warning] 
>  - 主语不出题
>  - 主干不出题

**小技巧：假设法**
	*如果判 F，哪个信息会出错？*

**方法论**
- **than x 2**：more than / rather than
- **绝对词/政治题考点**：most / only / first / all
