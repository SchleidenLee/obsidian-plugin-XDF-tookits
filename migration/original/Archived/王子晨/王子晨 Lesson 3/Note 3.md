# TFNG
### F和NG的区分
**兼容性判断**：
原文信息和题干信息能否共存？
	- 能：NG
	- 不能：F
### 判断题考点怎么找
1. **做假设**：如果要判F，哪个信息会出错？
2. **方法论**
	- more than / rather than 
	- most / only / first 过于绝对的表达
	- 方向性表达 *能找到反义词的* 
	2. 客观信息
		- 介词短语
		- 逻辑关系
