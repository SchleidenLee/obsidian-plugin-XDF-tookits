# XDF Feedback Generator

根据用户在反馈区域手动记录的关键点，自动生成完整反馈内容并替换写入到对应的 Obsidian 笔记中。

## 文件夹结构
```

/mnt/d/Schleiden/Obsidian/XDF/Current Class/  
├── 1111/ # 班级文件夹  
│ ├── 1111.md # 班级导航页  
│ └── 1111 Lesson 1/ # 课时文件夹  
│ ----├── 1111 Lesson 1.md # 课时导航页 (YAML: Date: YYYY-MM-DDTHH:MM) 
│---- ├── Feedback 1.md # 学员反馈（多个学员块，用 --- 分隔）  
│---- ├── Note 1.md # 课堂笔记  
│---- └── Homework 1.md # 课后作业


```

## 核心设计

### 通用标记

所有 AI 生成内容都用同一个标记：
- `<!-- AI_GENERATED_START -->`
- `<!-- AI_GENERATED_END -->`

### 结构驱动处理

| 结构 | 含义 |
|------|------|
| `### ` | 新块开始（班级反馈或学员块） |
| `<!-- AI_.*_START -->` | AI 生成内容开始，写入新内容 |
| `<!-- AI_.*_END -->` | AI 生成内容结束，停止跳过 |

awk 状态机按顺序处理，不需要匹配名字。

## 核心功能

### 1. 输入参数
- `--class <班级文件夹>` (可选) - 如 `3376`
- `--lesson <课时>` (可选) - 如 `Lesson 2`
- `--date <日期>` (可选) - 如 `2026-03-17`
- `--vault <vault 名称>` (可选) - 默认使用已设置的 vault

### 2. 工作流程
```

1. 搜索课时导航页 (通过 YAML Date 字段)  
    ↓
2. 读取班级反馈区域的原始记录  
    ↓
3. 生成班级反馈 → 替换写入  
    ↓
4. 读取 Feedback 文件  
    ↓
5. 状态机遍历所有学员块 → 逐个生成 → 替换写入

````

### 5. 空内容保护


```bash
# 提取原始记录内容（标记上方的内容）
raw_input=$(grep -B 10 "<!-- AI_GENERATED_START -->" file.md | grep "^- " | sed 's/^- //')

# 检查内容是否充足
if [ -z "$raw_input" ] || [ $(echo "$raw_input" | wc -l) -lt 2 ]; then
  echo "⚠️ 原始记录信息不足，跳过生成"
  exit 0
fi
```

### 7. 替换写入（awk 状态机，结构驱动）

```bash
# 通用替换函数（状态机，处理所有块）
replace_ai_content() {
  local file="$1"
  local content="$2"
  local tmp_file=$(mktemp)
  
  awk -v content="$content" '
  BEGIN {
    in_ai_block = 0
  }
  
  # 遇到 AI_START → 写入新内容，开始跳过
  /<!-- AI_.*_START -->/ {
    print
    print content
    in_ai_block = 1
    next
  }
  
  # 遇到 AI_END → 停止跳过
  /<!-- AI_.*_END -->/ {
    in_ai_block = 0
    print
    next
  }
  
  # 在 AI 区域中 → 跳过旧内容
  in_ai_block {
    next
  }
  
  # 其他内容 → 原样输出
  {
    print
  }
  ' "$file" > "$tmp_file" && mv "$tmp_file" "$file"
}

# 使用示例
replace_ai_content "课时导航页.md" "生成的班级反馈内容..."
replace_ai_content "Feedback 2.md" "生成的学员反馈内容..."
```

## 注意事项

1. **必须预先配置标记** - 所有 AI 生成区域都需要有 `<!-- AI_GENERATED_START -->` 和 `<!-- AI_GENERATED_END -->` 标记
2. **通用标记** - 使用 `<!-- AI_GENERATED_START -->`，不硬编码名字
3. **结构驱动** - awk 状态机按 `###` 和 `AI_START/END` 处理，不依赖名字匹配
4. **空内容保护** - 原始记录少于 2 条有效信息时跳过生成
5. **只参考用户手动记录** - 不看课堂笔记、作业等其他文件
6. **不修改 TODO** - 课时导航页中的待办事项保持不变
7. **输出连贯段落** - 最终反馈是一整段话，不是 bullet points
8. **语气平实** - 陈述事实，避免主观评价和情绪化语言
9. **幂等执行** - 重复运行会替换旧内容，不会追加重复
10. **awk 状态机** - 结构驱动，遍历所有块，不依赖名字匹配
